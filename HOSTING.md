## Deployment Instructions

### Initial Setup (Already Complete)
1. Repository created and configured
2. GitHub Pages enabled in Settings → Pages
3. Source branch set to `main`
4. CNAME configured for custom domain

### To Redeploy or Update

1. Make changes to your files in the repository
2. Commit and push to the `main` branch
3. GitHub Pages automatically rebuilds (usually 1-2 minutes)
4. Changes live at: https://vayusodh.github.io/VAYU-SECURE-PORTAL/

### To Update Custom Domain

1. Go to Repository Settings → Pages
2. Update the custom domain field
3. Update DNS records at your domain registrar:
   - Type: CNAME
   - Name: www
   - Value: vayusodh.github.io
   - Or use A records pointing to GitHub Pages IP addresses
